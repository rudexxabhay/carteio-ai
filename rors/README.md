## Evidence labels

- **Observed:** directly inspected in a browser or source tree.
- **Documented:** stated in Flowise's public website or official docs; not independently confirmed in its hosted application.
- **Implemented:** present in Carteio source. This label does not imply runtime validation.
- **Unverified:** blocked by access, environment, or the lack of an approved runtime check.
