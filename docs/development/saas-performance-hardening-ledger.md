## Reviewed areas with no additional change

- Dashboard overview (`frontend/src/dashboard-source/use-overview-data.ts`): the five independent initial reads already run concurrently with `Promise.allSettled`; an `AbortController`, slug-scoped result guard, and cleared loading state prevent stale workspace data from rendering. No duplicate-fetch or tenant-switch race was established in this hook.
- Conversation history (`ConversationOrchestrator`): history reads are bounded (40 rows for internal support context; 12 Playground turns) and select only required fields; provider context is further capped at 12 messages / 16 KiB. No safe limit reduction was justified.
- Connector sync (`ConnectorSyncWorker.runBatch`): sync/webhook claims run concurrently, while leased jobs are processed sequentially by type. No concurrency change was made because per-connection ordering/rate-limit behavior was not established as safe to parallelize.
- Knowledge source resolution: PUBLIC_VISITOR retains its public retrieval scope and uses a number-only resolver for `assignedSourceCount`; SPH-005 adds a differential assignment-set test (NOT_RUN). Source version, authenticated-PDF provenance and current-generation checks still run in retrieval before evidence use.

## Current scope

No database schema/index changes, provider changes, migrations, live Shopify operations, or cache changes are included. Phase 00 remains BLOCKED; this ledger does not close or modify the original roadmap.
